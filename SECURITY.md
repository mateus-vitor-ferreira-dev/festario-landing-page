# Política de segurança

## Como reportar uma vulnerabilidade

Reporte de forma **privada** pelo GitHub:

1. Abra a aba **Security** deste repositório.
2. Clique em **Report a vulnerability**.
3. Descreva o problema, como reproduzir, o impacto que você enxerga e, se tiver, uma sugestão de correção.

Não abra issue pública, PR nem post sobre a falha antes de ela ser corrigida.

## O que fazer

- Use só o mínimo necessário para demonstrar o problema.
- Dê tempo para a correção antes de divulgar qualquer detalhe.
- Se a falha envolver o app ou a API, reporte aqui mesmo: o caso é encaminhado.

## O que não fazer

- Não acesse, altere nem apague dados de outras pessoas.
- Não faça testes de negação de serviço, spam ou engenharia social.
- Não rode varredura automatizada em volume contra festario.com.br, app.festario.com.br ou api.festario.com.br.

## Prazo de resposta

- Confirmação do recebimento em até **5 dias úteis**.
- Depois disso, você recebe uma avaliação inicial e é avisado quando a correção for publicada.

## Escopo

Este repositório cobre o site estático em [festario.com.br](https://festario.com.br). Ele não guarda segredo: as variáveis `NEXT_PUBLIC_*` são públicas por definição.
